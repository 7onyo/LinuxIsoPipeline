Welcome to my custom **Debian Trixie** based operating system. This project provides a fully functional, ready-to-use live ISO that you can boot directly from a USB drive, as well as permanently install to your hard drive.

## Features & Roadmap
Currently, this serves as a clean, automated foundation, but it is being actively built out. Upcoming additions to the ISO include:
- **Pre-installed Extra Packages**: All the essential software you need right out of the box.
- **Custom Configurations**: Optimized settings, personalized themes, and system defaults.
- **Workflow Shortcuts**: Useful aliases, keybindings, and scripts to improve the daily experience.
- **Live + Installable**: Run it as a live environment on the go, or use the built-in installer to make it your permanent OS.

## Open Source & Compliance
This custom OS is built using unmodified upstream packages from Debian. The build scripts are fully open-source and available here. Source code for all included pre-compiled packages can be fetched directly via `apt-get source` within the OS. This is a community-driven project and is not an official release by the Debian Project.
